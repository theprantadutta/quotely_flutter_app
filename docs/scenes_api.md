# Scenes API contract

Scenes are short lines from movies, TV shows, anime, games and cartoons, spoken
by a character from a title. They are generated by the backend's AI pipeline
(the same `IAiExecutionService` + dedup flow used for quotes and facts) and
served to the Flutter app through the endpoints below.

Conventions match the existing API:

- Routes are `api/v1/{Controller}/{Action}`, `GET` only for the app, and every
  request carries the `X-Api-Key` header.
- JSON is camelCase (ASP.NET web defaults). Dates are ISO-8601 UTC.
- Paged responses wrap a list plus the existing `pagination` object
  (`pageNumber`, `pageSize`, `totalItemCount`). `getAllRows=true` returns
  everything (used by the offline "Download everything" pack).
- `seed` gives a stable random order across pages, exactly like quotes.
- IDs are strings.

## Types

`type` is one of `movie`, `tv`, `anime`, `game`, `cartoon` (lowercase).

### MediaTitleDto

```json
{
  "id": "string",
  "slug": "the-shawshank-redemption",
  "name": "The Shawshank Redemption",
  "type": "movie",
  "yearStart": 1994,
  "yearEnd": null,
  "genres": ["Drama"],
  "description": "One sentence about the title.",
  "posterUrl": null,
  "quoteCount": 12,
  "popularity": 87,
  "dateAdded": "2026-09-24T00:00:00Z",
  "dateModified": "2026-09-24T00:00:00Z"
}
```

`yearEnd` is null for movies, games and still-running shows (the app renders
`1999 – present` for a `tv`/`anime` title with a null `yearEnd`).
`posterUrl` is null unless an image API key (TMDB) is configured; the app
shows its striped fallback when it is null.

### CharacterDto

```json
{
  "id": "string",
  "titleId": "string",
  "titleName": "One Piece",
  "name": "Monkey D. Luffy",
  "avatarUrl": null,
  "quoteCount": 9
}
```

### SceneQuoteDto

Title and character fields are denormalized so a scene bubble renders from one
object with no extra requests.

```json
{
  "id": "string",
  "content": "Hope is a good thing, maybe the best of things.",
  "titleId": "string",
  "titleSlug": "the-shawshank-redemption",
  "titleName": "The Shawshank Redemption",
  "titleType": "movie",
  "titleYear": 1994,
  "posterUrl": null,
  "characterId": "string",
  "characterName": "Andy Dufresne",
  "characterAvatarUrl": null,
  "episodeLabel": "01:12:04",
  "season": null,
  "episode": null,
  "isSpoiler": false,
  "spoilerAfterEpisode": null,
  "tags": ["hope"],
  "likes": 0,
  "dateAdded": "2026-09-24T00:00:00Z",
  "dateModified": "2026-09-24T00:00:00Z"
}
```

`episodeLabel` is free text: `Ep. 4`, `S2 · E5`, or a timestamp for films.
It may be null. `spoilerAfterEpisode` is the absolute episode number after
which the line is no longer a spoiler (null when not applicable).

## Scene endpoints

| Action | Query | Response |
|---|---|---|
| `Scene/GetAllSceneQuotes` | `pageNumber`, `pageSize`, `getAllRows`, `types` (csv), `titleId`, `characterId`, `sort` (`random` default, `popular`, `episode`, `newest`), `seed` | `{ "sceneQuotes": [SceneQuoteDto], "pagination": {...} }` |
| `Scene/GetAllTitles` | `pageNumber`, `pageSize`, `getAllRows`, `types` (csv), `search` | `{ "titles": [MediaTitleDto], "pagination": {...} }` |
| `Scene/GetTrendingTitles` | `pageNumber`, `pageSize`, `types` (csv) | `{ "titles": [MediaTitleDto], "pagination": {...} }`, ordered by `popularity` desc then `quoteCount` desc |
| `Scene/GetTitleDetail` | `titleId` (id or slug) | `{ "title": MediaTitleDto, "characters": [CharacterDto] }`, or 404 |
| `Scene/GetAllCharacters` | `pageNumber`, `pageSize`, `getAllRows`, `search`, `titleId` | `{ "characters": [CharacterDto], "pagination": {...} }` |

## "Of the day" endpoints

These mirror `QuoteOfTheDay`.

| Action | Response |
|---|---|
| `SceneOfTheDay/GetTodaySceneOfTheDay` | `SceneOfTheDayDto` |
| `SceneOfTheDay/GetAllSceneOfTheDay?pageNumber&pageSize&getAllRows` | `{ "sceneOfTheDayWithScenes": [SceneOfTheDayDto], "pagination": {...} }` |
| `FridayNightLines/GetTodayFridayNightLines` | `SceneOfTheDayDto` (the most recent Friday's line) |
| `FridayNightLines/GetAllFridayNightLines?pageNumber&pageSize&getAllRows` | `{ "fridayNightLinesWithScenes": [SceneOfTheDayDto], "pagination": {...} }` |

```json
// SceneOfTheDayDto
{ "id": 1, "sceneDate": "2026-09-24T00:00:00Z", "sceneQuote": { /* SceneQuoteDto */ } }
```

## Generation (backend)

- `GenerateAiSceneJob` (Hangfire recurring) picks a media type and asks the AI
  for a real, well-known title that is not yet in the database or has few
  lines. The AI returns title metadata, 3–6 main characters and 6–12 short,
  famous lines, each at most 25 words and one or two sentences. No script
  passages. The job validates the JSON, dedups lines via
  `IContentDeduplicationService` (normalized content), and upserts
  title, characters and lines.
- Lines that reveal plot twists are flagged `isSpoiler` with
  `spoilerAfterEpisode` where applicable.
- Posters: when `Tmdb:ApiKey` is configured, the job resolves `posterUrl` from
  TMDB for movies and TV. Otherwise it stays null. The app shows the TMDB
  attribution in About.

## Notifications

| Job | Schedule | FCM topic | `data.routeName` |
|---|---|---|---|
| `SceneOfTheDayJob` | daily 12:30 UTC | *(none, in-app only; stored for Today)* | n/a |
| `FridayNightLinesJob` | Fridays 19:00 UTC | `friday_night_lines` | `/title/{titleId}?quote={sceneQuoteId}` |
| New lines for a title | after `GenerateAiSceneJob` adds lines to an existing title | `title_{titleSlug}` | `/title/{titleId}` |

FCM topic names allow `[a-zA-Z0-9-_.~%]`. Slugs are lowercase kebab-case, so
`title_{slug}` is always valid. The app subscribes to `title_{slug}` when the
user follows a title (and the "New from titles you follow" toggle is on).
